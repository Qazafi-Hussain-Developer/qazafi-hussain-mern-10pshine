# MERN (Node.js + React.js) Project

## Notes App

## Project Overview

This project aims to build a **full-stack web application** that allows users to **create, edit, and delete notes**. It includes **user authentication** to ensure privacy for each user and integrates **application logging, exception handling, unit testing, and database support (MySQL / PostgreSQL / MongoDB).**

---
